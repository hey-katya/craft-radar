About

Craft Radar is a short, curated list of open-source work for people who design and shape products. It is not a trending feed and not a directory of plugins.

Descriptions come from each repository's README. Stars, licences and dates were read from GitHub on . Entries have been read but not yet run, so treat them as leads to try, not as tested recommendations.

Some previews are the repository's own screenshots or demo frames. Where a repository has none, you see GitHub's generic card or a plain title tile. Licences differ: check each one before you reuse code.
